# 閱讀紀錄統計器

從文字檔讀取每日閱讀頁數，統計總頁數、紀錄筆數、
有閱讀的天數，以及達標天數。

## 功能

- 清理每行資料的頭尾空白，並排除空白行。
- 統計總閱讀頁數與紀錄筆數。
- 統計閱讀頁數大於 0 的天數。
- 統計閱讀頁數大於等於 20 的達標天數。

## 檔案

- `main.py`：讀取資料並輸出統計結果。
- `reading_pages.txt`：每日閱讀頁數，一天一筆。
- `README.md`：專案說明。

## 資料格式

在 `reading_pages.txt` 中，一行填寫一天的閱讀頁數：

```text
10

 20
0
35
15
```

- 每筆資料須為非負整數。
- 空白行不列入紀錄。
- `0` 會列入紀錄，但不算有閱讀或達標。
- 每筆非空白資料視為一天，程式不檢查日期。

## 執行方式

在 repository 根目錄開啟終端機，執行：

```bash
cd mini-projects/reading-tracker
python main.py
```

使用上述範例資料，輸出為：

```text
總閱讀頁數：80
紀錄筆數：5
有閱讀的天數：4
達標天數：2
```

## 測試紀錄

| 測試資料 | 總頁數 | 紀錄筆數 | 有閱讀天數 | 達標天數 |
| --- | ---: | ---: | ---: | ---: |
| 10、20、0、35、15，混有空白行與頭尾空格 | 80 | 5 | 4 | 2 |
| 只有 0 | 0 | 1 | 0 | 0 |
| 完全空檔案 | 0 | 0 | 0 | 0 |
| 只有 20 | 20 | 1 | 1 | 1 |

以上案例皆已手動測試通過。

## 目前限制

- 尚未處理非數字資料與檔案不存在的情況。
- 尚未加入負數檢查，輸入資料須自行確保為非負整數。
- 每日達標門檻固定為 20 頁。
